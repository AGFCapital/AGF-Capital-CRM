# Decisão pendente

Protótipo criado para escolher a estrutura visual inicial do CRM AGF.

Decisão registrada: o kanban precisa expor o fluxo completo, em sequência horizontal:
`Prontos para enviar → Aprovado → Convite enviado → Enviar mensagem → Em conversa → Agendamento → Call marcada → Concluído`.

Quando uma alternativa for escolhida, registrar aqui qual venceu e por quê; então transformar apenas a alternativa escolhida em interface de produção e remover as demais.
